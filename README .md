# Examining the Solution Behavior of Fuel Consumption Models in Green Vehicle Routing: MEET and CMEM

## About This Repository

This repository contains the base-case computational files used in the study entitled **“Examining the Solution Behavior of Fuel Consumption Models in Green Vehicle Routing: MEET and CMEM.”**

The study compares the solution behavior of two fuel consumption/emission calculation approaches, **MEET** and **CMEM**, when integrated into a Green Vehicle Routing Problem (GVRP).

The optimization models were solved using **Gurobi Optimizer**, while supplementary calculations were carried out in **Microsoft Excel**.

## Files

`MEET_CMEM_Basic_Models.xlsx`

This workbook contains the base-case calculations for the two models:

* **CMEM-Basic\_Light**: Base-case calculations for the CMEM formulation using the light vehicle class.
* **MEET-Basic\_Light**: Base-case calculations for the MEET formulation using the light vehicle class.

The workbook includes the parameters, network data, and fuel consumption/emission calculations used for the base-case comparison.

## Sensitivity Analyses

The manuscript also includes sensitivity analyses for changes in **customer demand** and **vehicle speed**.

These analyses use the **same mathematical model structures** as the base-case MEET and CMEM models. Only the relevant parameter values are changed for each scenario. Therefore, separate files for every sensitivity-analysis scenario are not included in this repository.

In other words, the shared base models represent the computational structure used throughout the study, while the sensitivity scenarios are generated by modifying the corresponding demand or speed parameters.

## Software

The computational study was conducted using:

* **SolverStudio** as the Excel-based modeling environment.
* **Gurobi Optimizer** as the optimization solver.
* **Microsoft Excel** for model implementation, supplementary calculations, and result evaluation.

A valid Gurobi license may be required to reproduce the optimization results.

## CMEM_Basic_Light

from gurobipy import*
from SolverStudio import*

m = Model()

x = {}
for i,j in arcs:
   x[i,j] =m.addVar(vtype="b")
   
y = {}
for i,j in arcs:
   y[i,j] =m.addVar(vtype="c")

m.update()

m.setObjective(quicksum(lamda*(friction_factor*engine_speed*displacement*
(d[i,j]/speed)*x[i,j]+ ye*beta*d[i,j]*speed*speed*x[i,j]+ ye*alfa*(curb_weight*x[i,j]+y[i,j])*d[i,j]) 
for i,j in arcs),GRB.MINIMIZE)

for a in customers:
   m.addConstr(quicksum(y[i,j] for i,j in arcs if i==a)==quicksum(y[i,j] for i,j in arcs if j==a)-demand[a])

for i,j in arcs:
   m.addConstr(y[i,j]<=vehicle_capacity*x[i,j])

for a in depot:
   m.addConstr(quicksum(y[i,j] for i,j in arcs if j==a)<=0)

for n in nodes:
   if n!="D":
      m.addConstr(quicksum(x[i,j] for i,j in arcs if j==n)==1)

for n in nodes:
   if n!="D":
      m.addConstr(quicksum(x[i,j] for i,j in arcs if i==n)==1)

m.addConstr (sum(x["D",j] for j in customers)<=vehicle_number)

m.optimize()

if m.status==GRB.OPTIMAL:
   for i,j in arcs:
      X[i,j] = x[i,j].x
      
   for i,j in arcs:
      Y[i,j] = y[i,j].x
        
   fuel_consumption = m.objVal

else:
     "No Solution"
